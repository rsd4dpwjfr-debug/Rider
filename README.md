# Abyss Rider — iPhone PWA

This is the original Abyss Rider HTML game prepared as a Progressive Web App.

## Contents
- index.html — original game, with only PWA metadata/service-worker registration added
- manifest.webmanifest — iPhone/Android install metadata
- sw.js — offline caching
- icons/ — app icons

## iPhone
The site must be hosted over HTTPS. Open it in Safari, then use:
Share → Add to Home Screen → Add.
